# Housing Price Predictor

Attempting to determine the price of houses using Kaggle data sets.

## Project Structure

- `data/`: Contains the dataset files (train.csv, test.csv, etc.)
- `notebooks/`: Jupyter notebooks for exploratory data analysis, feature engineering, and modeling
- `src/`: Python scripts for data preprocessing, model training, and utilities
- `models/`: Saved trained models
- `requirements.txt`: Python dependencies

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jmaulana0/housing_price_predictor.git
   cd housing_price_predictor
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Place the Kaggle dataset files in the `data/` directory.
2. Run notebooks in `notebooks/` for analysis and modeling.
3. Use scripts in `src/` for preprocessing and training.

## Data

Download the dataset from [Kaggle Housing Prices Competition](https://www.kaggle.com/c/house-prices-advanced-regression-techniques).
